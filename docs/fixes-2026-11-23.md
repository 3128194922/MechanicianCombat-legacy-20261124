# 2026-11-23 修复记录

基线：Forge 47.4.28 / Minecraft 1.20.1 / Java 17。

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 底衣穿戴后身体透明 | `MechanicianArmorGeometry.renderAll` 只传了 Feature 集合，`Part...` 为空，实际一个部件都没画 | 显式遍历 `Part.values()`；底衣跳过 HEAD，保留原版头部/头盔层 |
| 猎矛部署只有物品动画 | `PlayerAnimator` 的注册表只接受 Emotecraft `emote/moves`，读不了作者的 `animations/bones` JSON | 改为与战旗/跳跃推进器一致的手动通道采样 |
| 护甲模块不显示 | 本地玩家优先使用 `ArmorAbilityClientState`，状态包未到/滞后时会把已有的物品 NBT 模块判成未安装；第一人称也只画底衣手臂 | NBT 与状态包改为“任一为真”；第一人称补画胸甲手臂几何 |
| 灵魂锁链只有 1.5 秒 | 特效 30 tick 且立即结算一次伤害 | 链接改为 100 tick；期间成员受伤持续按 70%/50% 传递；客户端全程渲染、末 5 tick 淡出 |
| 背包核心装不上扩展 | 下方只有右下槽接受模块；拆掉发射器后模块还可能残留已安装状态 | 下方两个空槽都接受模块；模块安装严格跟随跳跃推进器/召唤天线类型 |
| 按 X 无事可做时仍翻滚 | 背包键与翻滚键撞键时仍会走翻滚；跳跃推进器的 X 还会落进便携发射器分支 | 撞键时翻滚让位；跳跃推进器不再响应 X（导弹舱仍用 X） |

## 验证

- `compileJava` / `compileGameTestJava`：通过。
- `check -x test`（全部离线资源/行为契约）：通过。
- `runGameTestServer`：64 个测试中新增的背包核心/扩展、灵魂锁链传递测试通过；仅既有 `completedslideextendsspeedonly` 失败（本次未改动滑铲移速尾段）。
- 未验证：真实客户端第三人称底衣/模块画面、猎矛玩家动作观感、5 秒锁链画面、用户实际键位下的 X 冲突。
